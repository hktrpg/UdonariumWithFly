## 五分鐘上手 {#quickstart}

1. 用 **Chrome／Edge** 開啟 https://z01.hktrpg.com/ ，選好語言後開始（或略過）引導教學。  
2. 打開 **連線** → 設暱稱 → **建立房間**（建議順便綁定**資料夾備份**）。  
3. 複製 **玩家邀請連結** 私訊給團員。  
4. **地圖** 上傳地圖圖；把角色圖拖進瀏覽器或從 **圖片** 上傳；空白處右鍵新增角色。  
5. 聊天選好 **BCDice 規則**；角色右鍵 →「作為我的角色」／需要時開聊天面板。  
6. **結束前**：確認資料夾已寫入，或再 **下載一份 ZIP**。

> 想自己練手：開兩個視窗（一般＋無痕）互相進同一房。

## 這是什麼、請先記住的三件事 {#about}

**Udonarium（烏冬）** 是在瀏覽器裡跑的桌遊／TRPG 虛擬桌面。本站是 [HKTRPG](https://www.hktrpg.com/) 改造版（基底為 [Udonarium with Fly](https://github.com/NanasuNANA/UdonariumWithFly)）：多語介面、光照／視野、戰鬥追蹤、鍵盤操作、資料夾備份、引導教學等。

### 必記三點 {#about-three}

1. **資料主要在玩家之間互傳（P2P）**  
   伺服器協助連線，但**不會**長期保管棋子、圖片、聊天紀錄。房間清空、全員離線後，線上桌面就沒了。

2. **離開前一定要存檔**  
   「下載 ZIP」或「資料夾備份」。不存就會像煙火一樣消失。

3. **建議桌面版 Google Chrome（HTTPS）**  
   資料夾備份依賴 File System Access API；手機／Safari 功能可能不完整。

| 項目 | 建議 |
|------|------|
| 瀏覽器 | 桌面 **Chrome** 或 **Edge** |

介面語言可在歡迎頁、連線面板或 **設定\*** 切換：繁中／简中／English／日本語（會記住）。

## 畫面與左側選單總覽 {#ui-overview}

典型畫面：中央是 2.5D 地圖；左側是功能選單；可拖曳開啟多個面板（連線、聊天、倉庫等）。

| 選單 | 用途 |
|------|------|
| **連線** | 暱稱、開房／大廳、身份、邀請連結、ZIP、資料夾備份、同桌玩家 |
| **聊天** | 多頻道、BCDice、聊天面板（指令板）、本機工具列 |
| **地圖** | 地圖圖、格線、黑暗、天氣、視野（FoW） |
| **圖片** | 共用圖庫（也可把檔案拖進瀏覽器） |
| **音樂** | 共用 BGM（ZIP 會一併打包已上傳音訊） |
| **工具箱** | 天氣／日夜、Cut-in、骰表、視角、ZIP／資料夾備份等快捷 |
| **戰鬥** | 先攻與回合追蹤 |
| **場景工具** | 燈光、牆壁、繪圖、文字（通常 GM） |
| **倉庫** | 角色：桌面／公用／私人／回收區 |
| **筆記** | 筆記倉庫：桌面／公用／私人／回收區 |
| **設定\*** | 僅本機：格線顯示、吸附、音效、立繪、語系、教學 |
| **切斷** | 離開房間並重新載入（請先存檔） |

標有 `*` 的設定通常只影響你自己的瀏覽器，不會改到別人桌上的內容。

## 房間、身份與邀請連結 {#room}

### 大廳與建立房間 {#room-create}

1. 打開 **連線**。  
2. 設定暱稱、顏色、玩家圖示（會存在瀏覽器）。  
3. **大廳**：搜尋並加入別人開的房。  
4. **建立房間**：房名；可設房間密碼；可設 **GM／玩家／訪客** 各身份為「開放／密碼／停用」。

進入房間後，桌面物件、聊天、圖片等會在同房玩家間即時同步。

### 三種身份 {#room-roles}

| 身份 | 概要 |
|------|------|
| **GM** | 可看密語、卡背、未公開骰、角色／游標位置等；負責場景工具與多數房間管理 |
| **玩家（User）** | 一般參加；可編輯桌面（受房間規則與「我的角色」限制） |
| **訪客（Guest）** | 功能大幅受限：無法 ZIP／資料夾備份、多數編輯與快捷鍵；主要觀看與受限聊天 |

連線面板可「轉換身份」（需該身份開放，且必要時輸入密碼）。

### 邀請連結 {#room-invite}

在房間內可複製：

- 複製 GM 邀請  
- 複製玩家邀請  
- 複製訪客邀請  

取得連結的人可直接以該身份進房（連結可含角色密碼）。

> **注意**：不要把含密碼的邀請公開貼到任何人都能看的地方；直播時也請小心。

邀請失敗常見原因：房間已空（需有人在線）、密碼失效、該身份未開放、你已在別的房間。

### 私人連線 {#room-private}

可用對方 ID 做私人連線（非房間模式）。在房間內時無法使用私人連線。一人測試建議開兩個視窗。

## 存檔：ZIP 與本機資料夾備份 {#save}

兩種機制可並用。**空房不會留在伺服器**，存檔是延續戰役的唯一可靠方式。

| 比較 | **ZIP** | **資料夾備份** |
|------|---------|----------------|
| 時機 | 手動下載／讀取 | 綁定後自動覆寫（也可手動儲存） |
| 適合 | 帶走、分享、跨裝置帶檔 | 同機持續戰役、少手動 |
| 瀏覽器 | 多數桌面瀏覽器 | 建議 Chrome／Edge＋HTTPS |
| 訪客 | 不可用 | 不可用 |

入口：**連線** 面板或 **工具箱**（空白處右鍵精簡選單不含這些項）。

### ZIP（手動帶走） {#save-zip}

| 操作 | 說明 |
|------|------|
| **下載 ZIP** | 把當下整房打包成一個檔（含圖片、已上傳音樂等），自行保管 |
| **讀取 ZIP** | 還原先前打包的狀態 |

- 不會自動存；每次結束前請自己下載一次。  
- 建議：**先建房再讀取**，其他參加者才能一起同步；本機單人測試也可直接讀。  
- 按 **F5／Ctrl＋R** 重新整理時，系統可能詢問是否先下載 ZIP；已綁定資料夾時會先嘗試 flush 再重整（訪客略過）。  
- **密語不會進 ZIP**；換了連線 ID 後舊密語也可能看不到。

### 資料夾備份（自動覆寫） {#save-folder}

在桌面 Chrome／Edge（HTTPS）綁定本機資料夾後，依房間自動寫入備份。

**入口（非訪客）**

- **綁定／重新授權**資料夾（重新整理後可能需再授權一次）  
- **儲存房間**：立刻寫出  
- **讀取房間**：列出備份、可刪除；未進房可先建房再載入  

#### 自動儲存規則 {#save-auto}

| 規則 | 說明 |
|------|------|
| Debounce 5 秒 | 變更後等 5 秒再寫 |
| 最短間隔 30 秒 | 遊玩中兩次成功寫入至少隔 30 秒 |
| 一房一檔 | `{roomId}.zip` + `{roomId}.meta.json`；同 roomId 覆寫 |
| 角色密碼 | 不以明文存放；用本機瀏覽器金鑰加密。換瀏覽器／裝置需重填 |
| 立即寫出 | 「儲存房間」、退出／換房、切訪客、登出、F5／Ctrl＋R、SW 更新重整前會 flush |
| 訪客 | 不可綁定、自動寫、手動存或從資料夾載入 |
| 進房不自動載入 | 即使本機有同 roomId 備份，加入線上房時**不會**覆寫 peer 桌面；載入一律手動 |

#### 還原語意 {#save-restore}

- **恢復房間**：沿用備份的 `roomId`（與名稱／開關／可解密時的密碼），之後自動備份覆寫同一檔。  
- 在**不同** roomId 的已連線房間載入：會以目前房間 ID 另存（fork）。  
- 載入進已連線房間：會覆寫桌面並同步給其他參加者——請先和團員確認。

## 地圖視角與基本操作 {#map-basics}

地圖是 **2.5D**：可平移、旋轉視角、縮放。

### 視角 {#map-view}

| 操作 | 效果 |
|------|------|
| **Ctrl＋左鍵拖曳** | 平移地圖 |
| **右鍵拖曳** | 旋轉視角 |
| **滾輪** | 縮放 |
| **Shift＋滾輪** | 左右移動畫面 |
| **Ctrl＋滾輪** | 上下移動畫面 |

工具箱可「視角重置」（預設／俯視）。

### 物件 {#map-objects}

| 操作 | 效果 |
|------|------|
| **左鍵拖曳** | 移動物件 |
| **拖旋轉把手** | 轉向 |
| **右鍵** | 該物件選單（翻面、抽牌、擲骰、切換圖像等多在此） |
| **雙擊** | 開啟詳情（角色／卡牌／牌堆／骰子／地形／筆記／遮罩／範圍等） |

在**空白地圖右鍵**可新增：角色、骰子、卡牌、筆記、地形、遮罩、範圍等。

圖片、音樂檔可**直接拖進瀏覽器**匯入。

## 選取、鍵盤快捷鍵、路徑移動、Ping {#controls}

完整一覽見 [附錄：快捷鍵速查](#hotkeys)。訪客多數編輯快捷鍵不可用。

### 選取 {#select}

| 操作 | 效果 |
|------|------|
| 左鍵點物件 | 選取（高亮） |
| 左鍵空白拖曳 | 框選 |
| Shift＋點 | 加入／移出多選 |
| Shift＋拖曳 | 加選框選 |
| 點空白／Esc | 取消選取 |

> **注意**：**Ctrl＋左鍵**是平移或路徑路點，**不是**多選。

### 鍵盤（需先選取） {#keyboard}

| 按鍵 | 效果 |
|------|------|
| **WASD／方向鍵** | 移動（可對角） |
| **Shift＋WASD** | 改變面向 |
| **Delete** | 刪除（角色進回收區） |
| **Ctrl＋C／X／V** | 複製／剪下／貼上（貼在滑鼠游標處；選取文字時仍可複製文字） |
| **Ctrl＋Z** | 復原 |
| **Ctrl＋Y** 或 **Ctrl＋Shift＋Z** | 重做 |
| **[** / **]** | 送到後層／前層 |
| **Alt＋滾輪** | 旋轉約 15° |
| **Ctrl＋Shift＋滾輪** | 旋轉約 45° |
| 拖曳放開時按住 **Shift** | 暫時不吸附格線 |
| **Esc** | 取消選取（路徑草稿中則取消路徑） |

**復原／重做範圍（本機堆疊）**：移動、旋轉、刪除、剪下貼上、圖層、路徑移動；場景工具的建立／刪除／微移。  
輸入框內的 Ctrl＋Z 仍由瀏覽器處理文字，不會動到桌面 undo。

### 路徑移動 {#path-move}

一次只對**單一 Token**（多選時只動最先選取的那個）：

1. 選取 Token。  
2. **Ctrl＋左鍵**加路點（可放開 Ctrl，路點仍保留）。  
3. **左鍵**點終點開始移動，**或**按 **Space** 以目前路點出發。  
4. **右鍵**＝取消最後一個路點；**Esc**＝取消整條路徑。  

路徑移動中地圖下方會顯示簡短 HUD 提示。路徑移動可被 Ctrl＋Z 復原。

### Ping {#ping}

| 操作 | 效果 |
|------|------|
| 地圖空白處**長按**約 1 秒 | 一般標記 |
| **Shift＋長按** | 警告標記 |

用於提醒所有人注意某個位置。

## 聊天、骰子、指令板、浮動對話 {#chat}

### 聊天面板 {#chat-panel}

- 上方可切換**頻道／標籤**。  
- 輸入區可選 **BCDice 規則**後直接打指令。  
- 可選發言角色（影響預設發言者、浮動對話、暫時視野等）。

#### 本機工具列（ON／OFF，只影響你） {#chat-toolbar}

常見項目：音樂／效果音／提示音／靠左／**列表模式**（相對氣泡，較易閱讀）／**精簡工具列**（收起標籤與工具列，只留輸入；右下小鈕可還原）。

### 快速擲骰 {#quick-roll}

在角色卡數值欄旁可一鍵把數值送到**目前聊天頻道**，交由 BCDice 結算。

### 聊天面板（Chat Palette） {#chat-palette}

角色右鍵 →「顯示聊天面板…」，可放常用指令與台詞，點一下就送出。

### 浮動式對話框 {#float-dialog}

- 以角色發言時，輸入常會預帶「」。  
- 「」**內文**會立刻顯示在該 Token 上方。  
- 可在角色右鍵或倉庫開關「顯示浮動式對話框」。  
- 各聊天標籤也可設定是否啟用浮動對話／立繪／過場等。

### 密語 {#whisper}

密語有身份與可見性限制；**不會進 ZIP**。換連線 ID 後舊密語也可能看不到。重要內容請另存。

## 角色、倉庫、筆記、立繪與高度 {#character}

### 角色與「我的角色」 {#my-character}

右鍵角色可：

- **作為我的角色**：開聊天優先選取、視野相關、**他人不可拖動**（每人通常限一個）  
- **作為我的視野角色**：啟用 FoW 時長留自己的視界（見 [地圖設定／視野](#map-fow)）  
- 顯示詳情、聊天面板、立繪設定、切換下一張圖像  
- 高度顯示、陰影、疊放、僅自己可見（隱身）等  
- 移至公用／私人倉庫／回收區；建立副本；加入戰鬥  

雙擊 Token（含立繪區）也可開詳情。

**隱身**：桌面上有「僅自己可見」的角色時，其他人看不到你的游標位置。

### 倉庫 {#inventory}

**倉庫**整理角色棋子：

| 分頁 | 意義 |
|------|------|
| 桌面 | 目前在地圖上的 |
| 公用 | 大家共用、尚未放到桌或暫存 |
| 私人 | 僅自己 |
| 回收區 | 刪除後暫存，可再拖回 |

### 筆記倉庫 {#notes}

**筆記**選單：依桌面／共用／私人／回收區整理文字備忘，方便團務紀錄與線索。

### 立繪（Stand）與高度（With Fly） {#stand}

- 角色可設 **Stand（立繪）**；聊天／標籤可控制是否顯示。  
- **設定\*** 可開關「顯示立繪」、清除所有顯示中的立繪。  
- 物件可調 **高度**；陰影會隨尺寸／高度變化。右鍵可顯示高度或歸零。

### 卡牌、骰子、地形等 {#cards}

翻面、抽牌、擲桌面骰、硬幣等多在**右鍵選單**（不是雙擊的唯一入口）。  
地形／遮罩可調高度、是否與燈光互動（擋光）等。

## 地圖設定：格線、黑暗、天氣、視野 {#map-settings}

打開 **地圖** 面板。

### 基本 {#map-basic}

- 地圖圖片、背景前後圖、背景濾鏡  
- 名稱、寬高  
- **網格**：關閉／方格／六角（直向・橫向）；顏色；可顯示座標；可始終顯示網格  
- 吸附可在地圖或本機設定調整  
- 可下載地圖圖、新增多張地圖並切換  

### 氣氛／光影與天氣 {#map-weather}

| 項目 | 說明 |
|------|------|
| 黑暗度 | 日／夜或滑桿 |
| 全域亮度 | 整體明暗 |
| 天氣 | 雨、雷雨、雪、霧、強風、櫻花、楓葉、沙暴、彩虹、極光、燃燒等 |
| 強度 | 弱／中／強／最大 |

工具箱可快速切天氣與日夜動畫。

### 啟用視野（戰場迷霧 FoW） {#map-fow}

勾選「啟用視野（擁有角色）」後：

- **玩家**大致只看得到「自己的視野角色」周圍。  
- **GM 不受限**。  
- 請在角色右鍵設定 **視野距離／亮光／昏暗光**，並勾 **作為我的視野角色**。  
- 聊天選發言角色＝**暫時**帶入視野；關該聊天窗即取消。長留請用「作為我的視野角色」。  
- 若已開視野但尚未設視野角色，畫面會提示。  

擋光規則概要：

- 角色 Token **恆擋光**。  
- 遮罩、地形預設擋光；右鍵可關閉「與燈光互動」。  
- 場景工具的牆／燈用來塑造走廊與光源（見 [場景工具](#scene-tools)）。

## 場景工具（燈光／牆／繪圖） {#scene-tools}

**場景工具**通常僅 GM（或經權限開放的玩家）。

常見模式：選取／燈光／牆壁／矩形／橢圓／多邊形／手繪／文字。

| 操作 | 說明 |
|------|------|
| WASD／方向鍵 | 移動已選場景物件 |
| Delete | 刪除 |
| Ctrl＋Z／Y | 復原／重做 |

| Esc | 取消當前繪製 |

## 戰鬥輪 {#combat}

打開 **戰鬥**：

1. （可選）新增多組戰鬥名稱。  
2. 桌面選取角色 → **加入選取**，或 **加入桌面全部**。也可角色右鍵「加入戰鬥」。  
3. 設定先攻骰、是否追蹤資源、是否「跳過敗北」。  
4. **全部擲先攻**／NPC 擲先攻／使用資源先攻／手動改先攻。  
5. **開始戰鬥** → 用回合⟶／輪⟹ 推進；有人可按「結束我的回合」。  
6. 可標記敗北、隱藏對玩家顯示、對焦棋子、結束戰鬥。  

**死亡**狀態與戰鬥「倒下／敗北」會**雙向同步**（見 [狀態](#status)）。  
空清單時介面會提示：先選取再加入，再擲先攻並開始。

## 訪客模式與權限 {#guest}

### 訪客限制（摘要） {#guest-limits}

無法：ZIP 下載／讀取、資料夾備份、編輯筆記、圖片／音樂庫編輯、地圖／工具箱多數編輯、多數編輯快捷鍵。  
主要可：觀看、受限聊天。

開房時可為 Guest 設開放／密碼／停用；仍支援舊版「允許訪客」概念。  
即使有邀請連結，房間若停用該身份仍進不去。

### 權限管理 {#permissions}

GM 可在連線相關介面管理權限（例如場景工具是否開放給玩家）。僅 GM 可管理。

## 建議流程（開團 checklist） {#checklist}

### GM 開新團 {#checklist-gm}

1. Chrome 開啟 https://z01.hktrpg.com/  
2. 連線 → 設暱稱 → **綁定資料夾備份**（建議）→ 建立房間（設好 GM／玩家／訪客規則）  
3. 複製各身份**邀請連結**私訊給團員  
4. 地圖：上傳地圖圖、調格線；需要時開黑暗／天氣／視野  
5. 圖片庫上傳 Token；右鍵放角色；設視野／我的角色  
6. 需要戰鬥時開戰鬥輪；需要迷宮時用場景工具畫牆與燈  
7. 團結束前：**確認資料夾已寫入**或再 **下載一份 ZIP** 雙保險  

### 玩家加入 {#checklist-player}

1. 用邀請連結或大廳進房  
2. 設暱稱；認領「我的角色」／視野角色  
3. 聊天選好 BCDice 規則；需要時開聊天面板  
4. 不要依賴「下次還在線上」——重要進度請催 GM 存檔  

### 下次續攤 {#checklist-resume}

1. GM 進站 → 建房或從資料夾「恢復房間」（同 roomId）→ 或讀取 ZIP  
2. 再發邀請；確認大家進的是同一房  
3. 若從資料夾恢復後密碼提示需重填，把角色密碼再存一次即可

## 常見問題 {#faq}

**Q. 為什麼大廳找不到昨天的房？**  
A. 空房會消失。請用 ZIP 或資料夾備份恢復。

**Q. 資料夾備份換電腦後密碼沒了？**  
A. 密碼用本機瀏覽器金鑰加密，換機／換瀏覽器需重填；填完再存一次即可。

**Q. 為什麼我拖不動別人的角色？**  
A. 對方可能已設「作為我的角色」；或你是訪客；或權限不足。

**Q. 開了視野一片黑？**  
A. 請右鍵自己的 Token → 設視野／亮光，並勾「作為我的視野角色」。GM 應不受限。

**Q. Ctrl＋左鍵變成路徑不是平移？**  
A. 已選取 Token 時，Ctrl＋左鍵會加路點。取消選取後再 Ctrl＋拖曳即可平移。

**Q. 復原沒反應？**  
A. 焦點是否在輸入框（此時 Ctrl＋Z 改文字）？是否訪客？該操作是否不在 undo 範圍？

**Q. 密語讀 ZIP 後不見？**  
A. 設計如此：密語不進 ZIP。請勿只靠 ZIP 保存密語內容。

**Q. 手機能用嗎？**  
A. 基本觀看可能可以，但鍵盤操作、資料夾備份、精細場景編輯等以桌面 Chrome 為準。

**Q. 連線一直失敗？**  
A. 檢查網路、防火牆、是否 HTTPS、後端是否正常。同房可看連線面板的連線狀態（良好／不良）。

**Q. 重新整理後資料夾備份失效？**  
A. 瀏覽器可能要求重新授權目錄。到連線面板按「綁定／重新授權」即可。

**Q. 讀取備份後別人桌面被蓋掉？**  
A. 載入進已連線房間會覆寫並同步給所有人。請先和團員確認，或先空房再恢復。

## 附錄：快捷鍵速查 {#hotkeys}

訪客多數編輯快捷鍵不可用。焦點在輸入框時，Ctrl＋Z／C／V 等由瀏覽器處理文字。

### 視角與畫面 {#hotkeys-view}

| 操作 | 效果 |
|------|------|
| Ctrl＋左鍵拖曳 | 平移（無選取／非路徑時） |
| 右鍵拖曳 | 旋轉視角 |
| 滾輪 | 縮放 |
| Shift＋滾輪 | 左右移動畫面 |
| Ctrl＋滾輪 | 上下移動畫面 |

### 選取與物件（選取後） {#hotkeys-object}

| 操作 | 效果 |
|------|------|
| WASD／方向鍵 | 移動 |
| Shift＋WASD | 面向 |
| Delete | 刪除（角色→回收區） |
| Ctrl＋C／X／V | 複製／剪下／貼上（貼在游標處） |
| Ctrl＋Z／Y（或 Ctrl＋Shift＋Z） | 復原／重做 |
| [ / ] | 後層／前層 |
| Alt＋滾輪 | 旋轉約 15° |
| Ctrl＋Shift＋滾輪 | 旋轉約 45° |
| 放開時按住 Shift | 暫時不吸附 |
| Esc | 取消選取／取消路徑 |

### 路徑移動（單一 Token） {#hotkeys-path}

| 操作 | 效果 |
|------|------|
| Ctrl＋左鍵 | 加路點 |
| 左鍵點終點／Space | 開始移動 |
| 右鍵 | 取消最後路點 |
| Esc | 取消整條路徑 |

### Ping／場景工具 {#hotkeys-ping}

| 操作 | 效果 |
|------|------|
| 空白處長按約 1 秒 | Ping |
| Shift＋長按 | 警告 Ping |
| 場景：Enter／雙擊 | 完成牆、多邊形等 |
| 場景：Esc | 取消繪製 |
